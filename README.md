# Example Project.
This is a simple script written in bash to run a webserver. I made this because I wanted to learn and handle the manual text in HTTP requests. All it does is displays a simple AI model chat. It works with the OpenAI, or Anthropic API.

I haven't implemented model streaming yet, planning to do that soon.

## Installation
To install this script run this command ```curl -fsSL https://raw.githubusercontent.com/username/project/main/install.sh | bash``` then run ```example``` in your terminal. 

## Requirements
This script works on macOS Golden Gate, I would assume it should work on most versions of MacOS. Linux support has not been integrated at this state. Most Macs should run it as it is a very light script.
